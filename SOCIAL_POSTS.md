## 1. LinkedIn Post

```markdown
🚀 Excited to unveil RadarFish — built for the TinyFish × Team Technojam workshop ("AI That Clicks") at Galgotias University!

Like most developers and students, I spend hours every week refreshing 10+ company career boards, fighting clunky ATS search bars, and sifting through expired postings. So I built the tool I’d actually use: an intelligent, agentic job & internship scraper powered by TinyFish.

RadarFish integrates all 3 core TinyFish endpoints into a unified 3-stage agentic pipeline (200 pts tier):

1️⃣ TinyFish Search API: Dynamically discovers live, active listings across ATS portals (Greenhouse, Lever, Ashby, Workday) using targeted query operators. No stale hardcoded URLs.
2️⃣ TinyFish Fetch API: Renders dynamic, client-side JavaScript SPAs via TinyFish’s managed Chromium fleet, extracting clean, structured markdown without anti-bot blocks.
3️⃣ TinyFish Agent API: Autonomous "AI That Clicks" for complex, interactive company career boards (Stripe, Uber, Google) — handling dropdown filters, pagination, and structured JSON schema extraction.

🎯 Key Highlights:
✅ User-defined preferences: Role, location, seniority, and custom skills
✅ Multi-factor AI Match Engine: 0-100% relevance score with transparent skill breakdowns
✅ Intelligent Deduplication: Merges cross-posted ATS listings into canonical job cards
✅ Direct Apply Links: Clean, tracking-free links directly to the company portal
✅ Auto-Refresh / Keep Fresh scheduler to catch new listings the moment they drop
```
